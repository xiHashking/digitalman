# VRoid 女教师草稿

`education-teacher-v1.vroid` 是本次在官方 VRoid Studio 2.14.0 中创建的可编辑工程，采用软件内置预设，没有购买第三方素材。

当前外观为黑色中长发、棕色眼睛、米色西装外套、白色衬衫、灰色马甲和长裤、深色条纹领带。紫色蝴蝶结已移除并保存。

## 面部修改进度

### 最新造型方向

用户要求更符合中国人审美，并继续保留成熟朴素的教师风格。当前采用的具体设计方向是亲和、知性的成年中国女教师，仍以动漫 3D 模型交付：

- 五官比例自然，杏眼保持神采，减少厚重上眼线与夸张瞳孔高光。
- 深棕虹膜、自然黑发、柔和且有毛流的眉形。
- 面颊、鼻翼、鼻梁和眼窝增加克制的明暗层次；保留柔和下颌，避免过尖下巴。
- 自然闭合的静止嘴形，淡玫瑰唇色与轻微气色，保持淡妆。
- 发型与服装贴近国内校园教师场景，整理现有发型并去除学生式领口蝴蝶结。

这些是造型方向，最终精细度仍需用户结合实际渲染效果评审。

已在编辑器中更换眼型组合、虹膜、带毛流的眉毛和唇部预设，并保存工程。实际近景截图为 `teacher-face-refinement.png`，完整编辑器截图为 `teacher-face-refinement-full.png`。截图不是生成效果图。

这仍是未完成草稿：上眼线偏厚，鼻梁与面颊层次不足，静止嘴部的白色缝隙不自然。用户已明确要求提高脸部精细度，不能将当前预设组合当成最终效果。需要继续调整眼睑比例、眼线及皮肤纹理，然后重新拍摄近景验证。

## 2026-10-14 导出与接入

已恢复正常 GUI 操作、保存工程，并通过 VRoid 导出为 `tablet_app/assets/three_d/education-teacher-v1.vrm`（VRM 1.0，约 16 MB）。文件已检查 humanoid 骨骼、blink 与 aa/ih/ou/ee/oh 表情。已加入独立 3D 预览内的形象下拉框，原有模型仍可选择。

平板上的加载性能、动作和口型仍需实际验证；App 需要重新打包才能包含新资源。

`teacher-initial-draft.vroid` 与 `teacher-v1.vroid` 是此前保留的草稿，未被覆盖。
