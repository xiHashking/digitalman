# Live2D classroom backdrop

`classroom-daylight.png` is an original backdrop generated with the built-in
imagegen tool for this project. It is rendered underneath the transparent
Live2D view; real-video mode is unchanged.

Prompt: Original bright empty modern school classroom, soft anime background
illustration, portrait composition, blank green chalkboard, cream walls, warm
wood floor, side-window daylight, desks at the edges and modest bookshelves.
Keep the center spacious for a full-body avatar or a seated schoolgirl with her
own desk. No people, foreground desk, text, logos or watermark.
